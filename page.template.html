Publication I of the edge-AI family

The Sovereign Edge Brain

A personal AI you own outright: it lives on your devices, learns for years while its neural weights never change, keeps every memory in a form you can read, syncs only between your own machines — by sound, radio, or light — and can refuse anything that exceeds a signed grant. No cloud, no telemetry, no landlord.

The load-bearing inversion: learning happens in the memory organ, not the network. The language model is a stateless, replaceable part. Your mind is your files, not their weights. The document of record is the README of this repository, anchored by its first commit; this page re-presents it and carries the gated reference law, runnable below.

1 · The memory organ

Memories are plain records — { id, weight ∈ [0,1], links[], topic } — stored content-addressed in twelve chambers with typed edges (working implementation: fall-remember, gated), placed by golden angle so they provably never cluster (golden-placer).

2 · The consolidation law — the dream cycle

weight ≥ κ (0.618) → KEPT, untouched weight < κ, linked FROM a kept record → WARM: held unchanged this pass otherwise → FADES: weight ×= κ a fade below the floor (0.05) → PRUNED, recorded at the weight it died at

Forgetting is a law, not a leak — the owner can read exactly why any memory faded. The estate's working overnight consolidator is the-dreamer: merge, type, generalise, resolve — weights unchanged, live on a consumer machine today.

3 · State as a number

The entire memory folds losslessly to one integer and back. A brain whose state is a number can be checkpointed, diffed, signed, sharded and carried on any medium. Full codec: geometric-computer, gated.

4 · Transport · 5 · The admission wall · 6 · The substrate

Sync between your own devices runs over one codec on three carriers (MCTP, with the working round-trip in one-ladder). Every action passes four doors first — identity, capability, replay, budget (chorus). Distributed computation over folded state is disclosed at GCN, drafted with sididy, the estate's resident mind.

What already runs · what must catch up

Gated and live today: the reference law in this page (31/31 mutants killed) · fall-remember · the-dreamer · geometric-computer · one-ladder · chorus · golden-placer — each mutation-gated in public CI.

The honest speculation: phone-class models good enough for daily reasoning (~2–4 years) · consolidation over millions of records on battery · carrier throughput. Not claimed: benchmark numbers, biological equivalence, or parity with gradient learning — only a personal mind that compounds, auditable where weights are not.
